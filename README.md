#  Student Result Checker

A simple web application that allows students to enter their name and marks to check their result.

##  Features

- Enter student name
- Enter marks from 0 to 100
- Check the result instantly
- Different messages for different marks
- Input validation for empty and invalid values
- Interactive button
- Dynamically generated result message

## Technologies Used

- HTML5
- CSS3
- JavaScript

##  Result Rules

| Marks | Result |
|------|--------|
| 90–100 | Excellent |
| 75–89 | Great Job |
| 50–74 | Passed |
| 0–49 | Keep Practicing |

## How It Works

1. Enter the student's name.
2. Enter marks between 0 and 100.
3. Click the **Check Result** button.
4. The application displays a personalized result message.
